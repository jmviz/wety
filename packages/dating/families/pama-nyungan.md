# Pama-Nyungan

**Shown in wety (2026-10-06).** Bouckaert, Bowern & Atkinson 2018, published MCC tree
(Supplementary Data File 2, 306 tips; manifest `bouckaert2018_pama_nyungan_mcc`):
root median 5578, 95% HPD 4456–6967 years. The SI gives years BP without an epoch,
read as AD 1950 by convention (labeled).

`aus-pam-pro` ends at the root: 5018–2507 BCE. The seven Tangkic languages, included
by the authors as a putative outgroup, fall inside the tree rather than at the root,
so the root is also the common ancestor of the 299 Pama-Nyungan languages. The root's
first split has support 0.06, so which branch separated first is uncertain. The main
article's rounded figures were not retrieved; the comparison is to the supplement only.
