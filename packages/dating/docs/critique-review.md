# Linguistic critique follow-up — 19 September 2026

The v2 overhaul corrected the central conceptual error: this is a registry of source-specific chronological evidence, not an inventory of language lifetimes. That correction survives inspection of the current export. The earlier audit nevertheless overstated some implemented guarantees, and implementing safeguards did not finish the pilots' evidence review. This follow-up distinguishes those two kinds of work.

## Disposition of the ten findings

| Finding | Current disposition | Remaining evidence work |
|---|---|---|
| 1. No universal language start | Addressed in synthesis and every code export: `spoken` remains null; catalog/ancestor references never become stage dates. | Define source-specific events before adjudicating a stage. Missing scholarship must not make a descendant older. |
| 2. Stem–crown is not a universal proto-period | Added explicit `model_lineage_span`; supported spans require endpoint claims from one supported analysis with joint samples. No routine manufactures a period from marginal medians. | Reconstruction-stage arguments remain separate; the current summary deposits cannot supply joint branch-span uncertainty. |
| 3. Entity definition and sampling | Exact descendant lists survive tree ingestion. Added literal source labels, separate catalog correspondence/certainty, geographic scope and competing identifications. Extraction now preserves explicit sampled taxa and actual method. | Identify omitted ancient/extant branches and adjudicate clade–catalog–stage relations. `mapping=exact` can mean exact source clade; it does not imply `catalog_mapping=exact`. No new Uralic aliases were exported. |
| 4. Tree adequacy and contact | Per-analysis limitations retained; prompts require contact and model conditions. A summary topology now records unobserved alternatives as unknown, rather than false. | Audit concentrated contact, scattered loans and tree adequacy for each model. Neither universal tree validity nor universal invalidity follows from borrowing. |
| 5. Evidential ranking and estimand/method/role | Removed residual instructions to override an allegedly rules-selected date or prefer Bayesian work. Preserve actual method independently of the legacy transport category; tree manifests explicitly declare prior/result role. | Review calibration independence, branch/time coverage, ancient-tip treatment, coding, concepts, synonyms, missingness, clocks and tree priors. More calibrations or a newer publication are not quality scores. |
| 6. Dependence and confidence | Added a typed research graph: studies, analyses, datasets, calibration sets and results; `reports_result_of`, `uses_prior_from`, critiques and replies remain different edges. The Uralic calibration reanalysis and Phlorest copy have explicit dependency records. | Graph completeness is not claimed. Shared data and priors for other scenarios still need annotation. | 7. Conditional versus historical uncertainty | Complete alternatives remain separate; no composite chronology is generated. Posterior ingestion now actually retains per-tree ages, parent sets and shared sample indices. Marginal distributions are excluded from hard parent–child contradiction checks. | Current pilots contain summaries, not joint posteriors. Compare entire analyses; no calibrated probability over all defensible historical accounts is supplied. |
| 8. Documentary and extinction semantics | Added composition, manuscript production, last documentation, last fluent-speaker report, regional shift and literary use events, plus location and competing identification metadata. ## Additional implementation defects repaired

* `program_verified` was a self-reported string at import time. Bundle validation now recomputes temporal normalization from native quantities. One-sided BP/BCE endpoints reverse correctly; a reported range can retain an unspecified probability instead of inventing 95%.
* A valid tree file hash did not establish that an imported record reproduced its numbers. Mechanical records are now compared with re-ingestion, including subject, role, time, analysis, result and provenance. Changed manifests produce changed evidence IDs; prior tree records are archived before replacement.
* Supported text spans could refer to an unrelated cached document. They must now belong to the registered source. Composite extraction inputs are proposals; a reviewed claim must cite the appropriate individual source text.
* Summary-tree topology had been represented as `topology_uncertainty=false`, and posterior sample arrays were not actually retained. These were documentation/implementation mismatches, now corrected and regression-tested.
* Completed batches were interpreted using the current prompt and source, even if those changed after submission. Request fingerprints now reject stale or unrecorded batch inputs. Old screening responses cannot acquire the new policy version.
* Retrieval could lose a usable partial text when a later URL failed or returned nothing, and partial results disappeared from totals. The best fetched text is retained, partial/excerpt counts are explicit, and replacement retrievals invalidate extraction metadata. Hash-mismatched cache text cannot silently feed a new extraction.
* Zhang 2020, Zeng 2025 and Neureiter 2022 still used the old raw-hash-as-text-key convention. Their existing text was reindexed under its actual hash. The previous candidate/extraction metadata survives in history; original bytes and parser remain explicitly unverified.
* Published CSV, evidence, review, research and coverage mirrors are now checked against the committed generation, not just the main JSON view.

## Pilot assessment

**Indo-European.** The deposited Heggarty main-M3 summary reproduces its conditional root median and HPD, not an agreed PIE date. Chang's primary text is recovered but has no replacement extraction. Heggarty's main-paper candidate remains abstract-only despite available deposited data. Compare ancestry constraints with sampled-ancestor treatment, and distinguish the full-family/Indo-Anatolian event from later non-Anatolian stages. Dataset reuse must be annotated before talking about independence. Kassian & Starostin is now registered and linked as a proposed critique of the Heggarty analysis; publisher retrieval returned a landing response in this run, so its detailed objections and any replies still require reading. Neither endorsement nor refutation is encoded.

**Uralic.** At the follow-up audit, Honkola, Maurits and Grünthal were recovered full-text candidates awaiting replacement extraction and claim review. The [19 September source packet](uralic-packet.md) now reviews selected assertions and dependencies, including Maurits's explicit AD 2000 epoch; a separate-session model review has since been completed and integrated (see the [agenda](next-steps.md)). Full extraction and project-held-out evaluation remain open. Honkola/Phlorest contributes 16 exact source-clade summaries. Maurits's cached full text confirms that the example repeats Honkola with replacement calibrations and changes the root mean by about 850 years while widening the HPD by almost 3,000 years. Its analysis is recorded as a methodological demonstration and cannot serve as a substantive historical default. Grünthal's contact/reconstruction/dispersal argument needs its own explicit dependencies; it is neither an unreasoned expert number nor a measured crown. Zeng's cached population-history text is available under its repaired text hash, with raw provenance unresolved. Genetic events and language-association hypotheses remain distinct. The old Parpola-based override is not an active adoption.

**Sino-Tibetan.** Sagart's recovered article and summary preserve the root **mean** and conditional HPD. Its uncertain basal placement and classical-text tip prior remain separate from a settled classification or earliest Chinese attestation. Zhang 2019 still lacks a recovered primary full text in the candidate pipeline. Zhang 2020's cached text explicitly reports nearly identical root ages with and without the Sinitic constraint, despite its older mean and broader taxon sample; no causal claim about the rooting constraint is warranted here. The previous archaeology-plus-crown interval and overall `high` confidence are not exported.

**Data construction.** [Snee, Ciucci & List 2026](https://academic.oup.com/jole/article/doi/10.1093/jole/lzag005/8736975) tests concept translation and phylogenetic topology, including effects on lower-level groupings. It does not quantify calendar-date errors. This distinction is now a development case and an explicit methodological checklist item. The source is registered; its readable publisher page was checked during this review, but a reproducible full-text cache was not recovered.

## What verification establishes

The suite has 70 offline regressions, and all three publication-reproduction checks pass. Twenty semantic development cases cover the major traps, including documentary dates, populations, critiques, topology, priors and model spans. Some are explicitly constructed negative controls; two publication cases remain labeled as review-supplied pending full-text verification. These are not twenty independent expert judgments or a held-out extraction score. No new model predictions were supplied, so semantic extraction accuracy remains `not_measured`.

The 225 deposited source-clade summaries and 3,562 total evidence records still yield zero promoted Wiktionary-stage chronologies across 8,625 codes. No new historical dates were adopted. The work remaining is documented in [the agenda](next-steps.md), with the live source inventory in `data/_derived/pilot_coverage.json`.
