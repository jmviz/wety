# Dating project agenda

The agenda serves a concrete operational goal: improve the autonomous research harness enough to investigate further language families with measured quality. Pilot review supplies failure cases, regression tests and better instructions; it need not resolve every historical controversy before a bounded new-family run. Track implementation and evaluation priorities in the [harness recommendations](harness-recommendations.md). Its useful output should be a defensible answer to “what event does this source date, for which entity and under which assumptions?” Keep the 225 deposited clade results as conditional model evidence and preserve unknowns for dictionary stages.
