# Language chronology: implemented version 2

The active scientific and operational contract is [dating/README.md](../packages/dating/README.md). The original implementation plan is preserved at [dating/docs/archive/language-dating-plan-v1.md](../packages/dating/docs/archive/language-dating-plan-v1.md); it is historical documentation, not the current specification.

The project now builds a provenance-bearing chronological evidence registry. A sampled-clade divergence, documentary sample date, attestation, conventional stage and contact hypothesis remain separate assertions. Unknown or disputed scope is retained; parent-family dates never become descendant language birth dates. Exact code-specific chronology requires reviewed evidence for that Wiktionary entity.

Implemented work and remaining scientific limits are tracked in [the overhaul audit](../packages/dating/docs/overhaul.md). Reproduction checks use three deposited analyses, including pinned Phlorest Uralic data. This replaces the impractical requirement for an existing specialist benchmark spanning all pilots with publication-fidelity tests, adversarial regressions and explicitly unmeasured semantic accuracy until independent predictions/review are available.

Next research work should prioritize primary-source recovery and stage mapping, document calibration dependency and topology sensitivity, and evaluate against frozen source passages before increasing automation. These are evidence-quality tasks; increasing the number of populated lifespan fields is no longer a goal.
